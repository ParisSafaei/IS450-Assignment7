## Project Description
Life Decision Helper is a Python program that helps
people decide whether they should buy something based
on their budget, the importance of the item, and
whether it is a necessity.

## Input
The user enters:
- Item name
- Item price
- Available budget
- Importance level from 1 to 10
- Whether the item is a necessity

## Output
The program recommends whether to buy the item,
wait before purchasing, or save money. It also
calculates how much money would remain.

## Python Concepts Used
- Variables
- User input
- Conditional statements
- Functions
- Arithmetic operations

## How to Run
1. Open myProgram.py in Visual Studio Code.
2. Run the Python file.
3. Answer the questions.
4. Read the decision report.
